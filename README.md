## Learning Path

A practical progression through this collection:

1. **Set up the environment**  
   Start with Breakout Lab Setup and understand the structure of a controlled CTF environment.

2. **Practice discovery**  
   Continue with Breakout Discovery to develop a structured approach to identifying potential breakout paths.

3. **Study Linux privilege boundaries**  
   Work through Sudo Sleepwalk and Sudo Sleep Root Awake to understand sudo-related security concepts.

4. **Investigate SSH and sensitive files**  
   Study SSH Shadow Sniffing and the security implications of exposed authentication-related information.

5. **Explore web security**  
   Complete the tabnabbing-focused challenges and connect browser behavior with service discovery.

6. **Study scheduled tasks and hardening**  
   Finish with Napping on the Job 2, Sleep Safe: Harden Linux, and Cron Drift: Sleeping Admin.

7. **Review Empire concepts**  
   Use Breakout with Empire Capabilities as an additional challenge for understanding security tooling and controlled post-exploitation concepts.

## How to Use the Labs

- Use every lab only in an authorized CTF or cybersecurity training environment.
- Complete enumeration before attempting a breakout or privilege-escalation path.
- Document permissions, services, scheduled tasks, authentication clues, and configuration findings.
- Treat shadow files and credentials as sensitive training data.
- For tabnabbing challenges, focus on understanding the web-security weakness and appropriate defenses.
- When studying sudo or cron, examine both the security risk and the corresponding hardening approach.
- Use security frameworks and tools only against systems where you have explicit authorization.
- Record defensive recommendations after completing each challenge.
